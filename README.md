# Dayboard

Dayboard is a lightweight task board for keeping daily work clear and moving. Organize tasks across To do, In progress, and Done, then focus on what needs attention today.

> This is my first app built with help from GitHub Copilot. I used conversation with Copilot to explore the idea, build the app, and refine it along the way.

## Features

- Create tasks with notes, labels, priorities, and due dates.
- Move tasks between To do, In progress, and Done.
- Search tasks and switch between the board and completed views.
- Keep tasks saved in the browser with local storage.
- Use the responsive layout on desktop and mobile.

Tasks are stored in the current browser on this device. They are not synced to an account or shared across devices.

## Getting started

You will need Node.js 20.19+ or 22.12+ and npm.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite in your browser.

## Scripts

```sh
npm run dev      # Start the local development server
npm run build    # Build the production app in dist/
npm run preview  # Preview the production build locally
```
